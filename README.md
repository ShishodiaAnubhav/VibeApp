# VigeApp

A full-featured blog application built with Flutter following Clean Architecture principles.
The application provides user authentication, blog publishing, image uploads, offline caching, and a scalable architecture using Bloc state management.

## Libraries Used
- Flutter Bloc
- Supabase
- Hive
- GetIt
- Image Picker
